### 🤖 [ProjectBrAIn](https://github.com/KFCGitten/ProjectBrAIn)
A localized RAG-driven development engine that indexes, analyzes, and synthesizes personal codebases into actionable AI insights. Built to serve as long-term memory for autonomous agents.

### 🌱 [PlantPal](https://github.com/KFCGitten/PlantPal)
A personal plant care assistant with CLI and web interface. Features automatic watering schedules, calendar generation, Discord notifications, and dynamic care tips powered by Ollama.
- **Tech Stack:** Python, HTML, Flask, Ollama (local AI), Discord API, `.ics` calendar export, Docker  
- **Showcase:** Demonstrates advanced full-stack design, robust CLI & Web interface, and practical AI-integration beyond the basics.

### 🧭 [KrisKompassen](https://github.com/mahtabb90/Kriskompassen)
A team-built Progressive Web App that brings local Swedish crisis information — public warnings (VMA), civil-defense shelter lookup, and preparedness guides — into one offline-capable place. Built in a 5-person Scrum team; contributed backend/data integration work on shelter data from Myndigheten för civilt försvar, bounding-box map queries, and offline caching via IndexedDB.
- **Tech Stack:** React (PWA), Python backend, MapLibre GL JS, IndexedDB, Scrum
- **Impact:** Demonstrates collaborative full-stack delivery on a real civic-tech product with offline-first UX
